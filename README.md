# PiP Clock

PiP Clock is a minimal fullscreen analog clock published on GitHub Pages:

https://saadchdhry.github.io/pages/

Its main purpose is not just telling time. It is designed to be a clean default pinned tab that you can jump back to when you want your current browser tab to move into Picture-in-Picture mode. That makes it especially handy for browser-based video calls, screen sharing, and video playback.

## Why this exists

Keeping a calm, useful placeholder tab open can make PiP workflows feel smoother. Instead of switching back to a blank tab or a noisy home page, you land on a clock that stays readable and out of the way.

## Good use cases

- Keeping a pinned standby tab for PiP-enabled meeting tabs
- Returning to a neutral tab during video calls
- Watching videos while working in another app or tab
- Using a fullscreen clock on a second monitor
- Using a lightweight ambient clock during focused work

## Technical notes

- Single self-contained `index.html`
- Inline SVG analog clock
- No build step
- No external dependencies
- Theme and display preferences persisted locally
